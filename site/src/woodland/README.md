# 林间时钟

可自由环绕观察的三维蚂蚁时钟。工蚁搬运同一批有重量的石头，把它们摆成时间；用户可以落石、改变观察角度，并体验昼夜、季节、风、雨、雪与薄雾。

这份工程是从固定视角 Canvas 版本重构而来的独立三维实现。最终产物为一个自包含 HTML：Three.js、Rapier WebAssembly、PBR 贴图和应用代码全部内嵌，运行时没有 CDN、API、登录或服务器依赖。

## 运行与构建

打开单文件成品 `antkeepers_woodland_v5.html` 即可使用。浏览器需要支持 WebGL 2 和 WebAssembly。HTML 成品另附；源码 ZIP 不重复包含成品，按下面的命令构建即可生成。开发工程采用固定版本依赖：Three.js 0.180.0、Rapier 3D Compat 0.21.0、esbuild 0.25.10。

```bash
npm ci
npm run build
```

默认生成 `dist/antkeepers_woodland_v5.html`。也可以指定完整输出路径：

```bash
node build.mjs /your/output/antkeepers_woodland_v5.html
```

```bash
npm run test:physics
npm run test:ants
```

物理测试是实际 Rapier 仿真，检查实体身份、位移、任务收敛和数字布局；关节测试检查锁足、支撑点、腿长和有限矩阵。真实浏览器的交互与画面仍需要另行检查。

## 极简界面与交互

页面只保留小号时间、只读季节/天气/温度，以及“靠近蚁群”“回到全景”“沉浸观察”三个按钮。品牌标题、标语、英文说明、指南、环境设置、时间跳转和右下控制栏已删除。默认自动跟随浏览器本地时间与季节，天气自然演变。所有可见文案均为中文，后续网站集成时可由宿主接入双语适配。

| 操作 | 行为 |
| --- | --- |
| 鼠标左键拖拽 | 绕当前观察中心旋转相机 |
| 滚轮 / 双指捏合 | 调整观察距离 |
| 右键 / 触屏长按 | 射线求交地面，在落点上方释放一颗有重力的石头 |
| 靠近蚁群 / 回到全景 | 相机平滑过渡，所有实体坐标保持不变 |
| 沉浸观察 | 隐藏时间、天气及另两个按钮，保留“显示界面”以便退出 |

快捷键：H 回到全景，Escape 退出沉浸。右键落石和触屏长按落石继续有效。时间目标、投喂、环境预览和暂停仍可通过本地诊断接口调用，页面不再显示相关控件或旧快捷键。

### 启动优化

启动时显示“你那里现在几点啦？”，较慢时与“谢谢你愿意驻足停留。”轮换。完整场景和贴图准备好就淡出，不设置最短问候展示时间；正常淡出为 0.25 秒，减少动态效果偏好下立即移除。

物理引擎初始化和固定环境贴图解压在启动早期并行开始，JPEG 的准备也与造景及物理构造重叠。相同计算结构的自然材质共享着色器程序，每种材质的风、湿润和积雪系数仍独立保存；静止材质继续省略风的计算。首次展示前通过异步编译准备材质，完整森林、蚂蚁和石头一次显示，不靠后续追加场景对象缩短加载屏。

原来每次打开页面都要重新生成的固定环境反射已预烘焙为 384 × 512 RGBA16F CubeUV 数据。可逆整数预测、字节平面重排和 gzip 保留全部半浮点数据；不会降低纹理尺寸或量化颜色。`prepareEnvironment()` 只解压 CPU 数据，创建场景时直接上传。在本次验证浏览器/GPU 上，与原即时 PMREM 数据、GPU 上传结果及六种 PBR 材质对照画面逐位/逐像素一致；其他 GPU 即时计算原始着色器时可能有末位舍入差异。不支持原生解压或解码失败时，自动使用原算法。

普通构建使用已生成的数据，不需要浏览器。只有主动修改固定环境算法、需要重新烘焙时才运行以下命令；需另行提供 Playwright 和 Chromium：

```bash
node src/bake-environment.mjs --write \
  --browser /path/to/chromium \
  --playwright /path/to/playwright
```

## 架构与权责

| 模块 | 负责内容 | 不应越过的边界 |
| --- | --- | --- |
| `src/main.js` | 启动、相机、UI、输入射线、固定步进、画质适配、环境时刻 | 不能为切换时间而重建石头；不能把天气时间直接变成布局重置 |
| `src/simulation.js` | 持久石头、Rapier 世界、任务规划、导航、拾取/搬运/放置、碰撞后的搬回 | 布局规划只能创建任务，不能修改实体姿态 |
| `src/rocks.js` | 稳定种子决定的三维石头、共用材质、湿润变化 | 不能按帧重新随机形状、纹理或颜色 |
| `src/ants.js` | 三维身体、世界锁足、两骨 IK、触角、姿态、口器位置 | 不能修改逻辑蚂蚁位置或石头状态 |
| `src/habitat.js` | 三角地形、准确高度查询、树根、木头、植被、地面材质 | 天气变化不能重建地形或固定障碍 |
| `src/forest.js` | 环绕空地的三层森林、树干分枝、林冠、幼树、灌丛与视线过渡 | 只扩展视觉环境；不能改变核心地形、碰撞体或石头 |
| `src/atmosphere.js` | 近似太阳/月亮轨迹、天空、阴影、雨雪、露水、湿润/积雪状态 | 不参与石头分配和时间布局 |
| `src/habitat_textures.js` | 内嵌的 Poly Haven CC0 土壤/树皮 PBR 贴图 | 应在首个可见场景帧前等待解码完成 |
| `src/environment.js` / `src/environment_data.js` | 固定反射图集的无损解码、缓存及纹理创建 | 不改变动态天空、天气或时刻 |
| `src/environment_source.js` / `src/bake-environment.mjs` | 原始反射算法、运行时回退与离线预烘焙 | 原始算法和预烘焙数据需共同更新 |

### 世界坐标与相机

采用 Y 向上的真实三维坐标。主要可交互地面为 X ∈ [-18, 18]、Z ∈ [-14, 14]；时钟位于 X 约 [-8.25, 8.25]、Z 约 [-3.3, 0]，储石区在右前方。外围林地延伸到更远处，以支持任意方位观察。外围远景只承担视觉环境，核心地面、树根和落木进入物理世界。

相机使用 PerspectiveCamera + OrbitControls，有俯仰与距离限制。窗口大小变化只调整投影和渲染分辨率。手机使用更宽视角并拉远全景距离，以容纳四位数字。相机高度受地表约束，减少穿入坡面的情况。

### 环绕森林与远景

外围森林由固定在世界坐标中的三维实例组成：空地边缘的树木与灌丛、中距离互相遮挡的树群、更远处高低错落的林冠。树木位置由独立种子和分片密度生成，避免等距排列；新增森林不消耗原有场景的随机序列，因此原来的近景树根、植被和物理障碍保持稳定。保留原先的外围树木，延伸外景地面，并逐渐压暗林下土壤，让空地自然过渡到林中。

高画质增加 362 棵主树、52 棵幼树、779 个林冠簇和 125 个灌丛。树干、树枝、阔叶与针叶轮廓使用实例化绘制，共增加 9 次绘制调用。低画质使用较少的固定树木和叶片；两种画质都没有随相机距离切换的树群层级，也不会在环绕时重新生成森林。新增外景树木不投射实时阴影，以控制成本；原有近景阴影保留。

森林材质共用环境光、距离雾、风、湿润、季节和积雪状态，清晨、黄昏和夜晚会呈现不同的色调和纵深。相机与空地之间的新增树枝、树叶和树干采用连续的局部可见性过渡，保持核心场景可观察；空地后方的森林保留完整。树木位置和几何体始终不变。这部分是观察体验所需的视觉处理，不是树木的物理移动。

### 石头的生命周期：连续性是硬约束

1. 创建时一次性确定 `id`、`seed`、几何体、材质色、刚体和碰撞体。渲染网格与物理凸包使用同一组几何顶点。
2. 投石产生一个新的动态刚体，重力、摩擦、旋转、弹跳和石间碰撞由 Rapier 处理。
3. 石头落稳后可以被分配给一只工蚁。一个实体只能同时有一个搬运任务和一个携带者。
4. 拾取把同一个刚体切换为位置驱动的运动学刚体，从当前位置平滑进入真实口器附近。
5. 搬运路径考虑载荷中心和其他石头的占用，不只考虑蚂蚁自身的中心位置。
6. 放置用连续轨迹降低石头，完成这一步的物理积分后，再把同一个刚体切回动态模式。
7. 如果碰撞确实推偏了已摆好的数字，等待它稳定，再派工蚁搬回同一个实体。禁止直接修正坐标。
8. 连续提交多个时间时，保留最新目标，先完成当前物理搬运批次，再规划下一批。用户额外投下的石头不会因时间变化而被删除。

石头总数上限为 360；达到上限会拒绝新增，已有实体仍全部保留。极简界面不显示常规操作说明，最近一次操作状态保存在诊断入口 `view.lastNotice`。页面重新加载会重新建立一个世界，当前版本没有跨刷新存档机制。

### 地形与足点

`heightAt()` 与渲染地面的三角网格使用同一份数据和三角插值；物理固定碰撞体也来自这组顶点。蚂蚁脚下的高度查询还近似考虑碎石起伏，尚未对每只脚进行逐三角形的石面接触求解。已经支撑的脚保存世界坐标，迈步时才转移支撑；股节和胫节长度保持固定。上坡、转身和搬运时，口器位置由模型提供，逻辑层据此驱动石头；前方地面抬高时，抓持姿态会配合抬头。

### 昼夜、季节与天气

环境时钟默认跟随浏览器本地时间。诊断入口可将光照停在任意小时，或设置四分钟浏览一天的模式；这些预览不再显示为页面控件。太阳路径使用温带北半球的近似纬度和太阳赤纬，月亮为氛围化轨迹。

自动天气按固定种子、季节、日期和六小时天气段产生，经过平滑过渡；不会按渲染帧重新随机。雨、雪和萤火虫处于世界坐标，旋转相机后仍在同一片林地中。雨滴按真实地面高度落地，雨圈沿地表法线放置。

湿润、露水和积雪是有记忆的状态：雨停之后地面逐渐变干，雪随温度融化。它们调整材质粗糙度、颜色和表面覆盖。季节也影响植被色调、温度与天气概率。夜间有冷色月光和少量克制的萤火/蘑菇光泽。

## 实施顺序与后续演进

当前已完成的一轮工程按以下依赖推进：

1. **世界与实体基础**：统一坐标、几何地形、持久刚体和相机；先保证旋转视角时一切仍是同一个世界。
2. **石头与蚂蚁**：凸包碰撞、重力、PBR 石头、关节蚂蚁、足点和口器合同。
3. **时钟行为**：任务分配、连续拾取/搬运/放置、动态载荷避障、碰撞后的真实搬回。
4. **自然环境**：Poly Haven 的 CC0 PBR 地面与树皮、林地植被、360° 分层森林、日夜、季节、雨雪、湿度与露水。
5. **交互和验证**：极简中文界面、桌面/触屏控制、手机全景适配、数值回归、真实浏览器画面与错误检查。
6. **启动优化**：固定反射预烘焙、共享材质程序、并行准备、首次展示前完整编译，以及同条件冷浏览器启动比较。

后续能继续提高真实感的主要方向，按依赖排序：

- **更精细的生态行为**：气味场、信息素路径、觅食竞争、低温/强降雨下的活动变化、遮蔽处避雨。当前任务行为服务于“蚂蚁时钟”，不是完整的生物学模型。
- **连续接触导航**：把地形、根、石堆和植被障碍统一为可行走表面，进一步处理复杂立体攀爬与多蚁相遇；目前是地表导航、碎石支撑和外围障碍规避。
- **体积材质与流体**：真正有厚度的积雪、脚印、雨水汇流、可变形湿泥。当前湿润和积雪主要是连续材质状态，没有完整水文或软体土壤仿真。
- **更高质量资产**：扫描级植物、更多局部形态变化、更精细的微距蚂蚁网格与毛发。现有蚂蚁、植被和石头为程序化网格，Poly Haven 的 PBR 贴图用于泥土和树皮。
- **图形升级**：接触阴影、屏幕空间环境遮蔽、体积雾/体积云、局部水面反射。当前是阴影贴图、PBR 环境反射、程序天空和距离雾，没有光线追踪。
- **部署与设备分级**：接入个人网站时，可把贴图/引擎拆成缓存资源，按设备加载不同细节；当前单文件优先便于直接打开、保存和交接。

## 已知边界

- 这是真实三维场景与刚体仿真，但不是照片级扫描重建。
- 没有联网获取真实天气，也没有定位请求；温度为场景气候模型，不是预报。
- 物理量采用微缩场景的世界单位，没有宣称一比一生物力学比例。
- 通过诊断接口设置的光照、季节和天气预览平滑过渡；暂停世界后需要继续运行，才能观察天气过程的发展。
- 实际性能取决于设备 GPU、分辨率和浏览器。自动画质调整渲染分辨率，不删减已经存在的石头。
- source 中的 `window.__ANTKEEPERS__` 是本地诊断入口，可读取状态并执行测试，不包含网络服务或账户数据。

## 工程打包与验证记录

`package-source.py` 使用 Python 3.8+ 标准库，打包源码、原始贴图、许可证、可移植测试和明确通过的验证记录。它排除依赖目录、内部浏览器脚本、截图和诊断中的失败报告；检查素材哈希、固定归档顺序和时间戳，并在写入后检查 ZIP 完整性。

```bash
python3 package-source.py --list
python3 package-source.py --output antkeepers_woodland_3d_source.zip
```

`verification/` 中的 JSON 是开发阶段的验证快照，不会被运行测试时覆盖。不同记录对应各自检查的构建和范围，带字节数或 SHA-256 的记录可进一步核对对应版本；不要把所有快照理解为对同一构建重复执行了全部测试。`SOURCE_MANIFEST.json` 记录交付源码、素材和验证快照的字节数及 SHA-256。

`verification/qa/forest-regression-report.json` 对应新增环绕森林这一轮：检查桌面多个方位、手机全景与低角度、黄昏/薄雾/夜景、浏览器错误和运行时网络请求；对比扩展前后的核心地形与 36 个碰撞网格，并检查静观环绕时石头实体身份和位置。蚂蚁、石头、物理调度和时间逻辑源码未改动，因此本轮没有重复执行整套长期搬运仿真；该部分保留前一阶段的验证快照。

`verification/qa/environment-prebake-report.json` 记录固定反射的无损重建、纹理参数、GPU 上传、PBR 对照和旧浏览器回退检查。`verification/qa/startup-cleanup-report.json` 记录本轮启动前后比较、极简界面、交互与几何连续性检查；软件 GPU 的计时用于同环境相对比较，不代表用户设备的绝对加载时间。
