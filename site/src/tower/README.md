# 回廊钟塔 · 1.6.0 昼夜人流与门口收尾

**下载后直接双击 `clockstairs-v1.1.html`，用支持 WebGL2、开启图形加速的现代浏览器打开即可。** 文件名沿用旧名称，页面内部已是 **1.6.0**。不需要安装 Node 或启动服务器，可以离线运行；源码包中的同一入口是 `dist/index.html`。

打开右上方原有的楼层选择，新增两处入口：**“内庭 · 水庭与花圃”** 和 **“园林 · 林荫步道”**。选择后就来到对应的观察位置，仍可拖动转头、WASD 移动、Q / E 升降。想看书墙，可以选择“2 层”或点“漫游”，再沿外墙走近藏书室。

## 本次更新

**以原来的人数作为夜间基准，白天目标为三倍。** 桌面默认夜间 48 人、白天 144 人；窄屏触控设备默认夜间 24 人、白天 72 人。已有保存的 `count` 继续表示夜间基准，重新打开不会把白天人数再乘一次三。

| 页面显示时段 | 人数目标 |
| --- | --- |
| 22:00–06:00 | 夜间基准 |
| 06:00–09:00 | 平滑增加到三倍 |
| 09:00–18:00 | 三倍夜间基准 |
| 18:00–22:00 | 平滑回落到夜间基准 |

人数由页面时钟驱动，手动预览时刻同样生效，云量和下雨不把白天误判为夜间。新世界初次显示时按当前时段安排人数；已打开的世界改变时间后，人们会实际进出，人数不会整批跳变。正在过桥、乘电梯、收书或游园的人先完成当前行程；已经上路的进出不会因反复调时掉头。

三座小门亭接到原有园林步道。额外访客从遮蔽的后室走出，沿门廊、台阶进入图书馆；离馆时走回门亭。镜头能看见后室或正在跟随此人时会延后隐去，避免看到人凭空消失。七层回廊增加 297 处经过实体净空检查的短暂停留位置，连同原有 67 处家具活动点，为白天人流保留换位余量。没有为人数增加界面文字或按钮。

门口同时继续收尾：六扇大门的开角收至 75°，石窗台与书柜后部重新留缝，凸出楼面的灰色环带退到楼板下，避免门、窗台、柜脚和墙面互相穿插。所有变化落实到实体网格；门口详细测量和当前验证范围见 `qa/door-clearance-results.json`。

## 场景里有什么

下方空地分成两座可以进入的花园。建筑内部是围绕升降塔的静水庭院，有环形步道、花圃、低矮灌木和阅读长椅；建筑外部是衔接门廊的林荫园林，有树木、花草、藤架和沿环路分布的停留处。三处外门和三处内庭阶梯都有实际开口、踏步与地面连接，人和自由相机都可以通过。

人物继续使用固定身份和原有模型，按昼夜安排额外访客。居民仍可在同一座花园完成两个停留点，再回原来的室内位置。园林休闲访问按实际在场人数安排，上限为桌面 8 人、移动端夜间 4 人及白天最多 8 人；已在进行的访问正常完成。入馆和离馆使用单独的生命周期，不占用园林长椅名额。

七层外墙增加连续嵌入的藏书柜：高柜接近檐口，低柜沿窗下展开，上方还有横向书架，保留窗光和三处出入口。新增书墙模块包含 **21,388 册实体几何书、333 个柜段、1,899 块层板和 3 架木梯**。原来的阅读区、家具、人物活动点与还书台继续使用。

园林共有 **4 条环形步道、18 个活动点、9 张长椅、3 座藤架、9 处花床、9 棵树和 18 盏灯具**。植物色彩随季节过渡，夜间灯具渐亮，降雨改变地面的湿润感；调整时间或天气不重新生成植物和路线。统计来源见 [园林结果](qa/baseline-v1_5_0/garden-results.json) 与 [书墙结果](qa/baseline-v1_5_0/library-walls-results.json)。

没有新增常驻文字按钮；两个花园入口放在已有选择器里。模型、材质和声音仍在本地生成，运行时不请求 CDN、字体、图片、模型、天气接口或音频文件。自动天气是钟塔生成的天气，不是所在地的实时预报。

所有入口和视角按钮都只负责定位，不会锁定后续移动。楼层切换使用短暂淡入淡出；人物自己的行走则连续经过实际通路。相机高度范围已扩展到较低的园林地面，外门、台阶和基础地面参与碰撞，建筑剖切不会把整座花园一同切掉。

这是一台可升降的观察相机。看向上方或正下方时按 W，仍沿水平方向前进；用 Q / E 主动调整高度。滚轮沿视线移动。墙、书柜、楼板和天花板会挡住移动，在中庭开口内可以连续升降；想直接换层，用右上选择器。

## 读时间与看天气

**短、宽、铜木色的是时桥；长、窄、蓝灰色的是分桥。** 顶层屋檐上的十二个罗马数字固定在建筑上，转动观察角度后仍能找到十二点。两桥会在不同高度接通回廊和中央升降塔。

首次打开跟随设备当地时间。手动设置的时刻继续正常走动，并显示“演示”标记。“看一圈”只演示一次：分桥在 26 秒旋转段内走完一小时，然后回到普通示意计时；点“此刻”回到当地时间。修改时间或到达楼层时，机构会先让正在跨接缝的人走稳，再收踏板、转动和重新接通。

清晨、白天、黄昏和夜间有各自的天空与光线。想看星空，可以把时刻设为 02:00、把“窗外”设为晴天，然后抬头；天空使用安全校时后实际生效的时间。雨夜的星光受该方向云层遮挡。两桥扶手、回廊、中央升降塔和花园的暖灯在入夜时逐渐亮起。

中央塔有固定雨盖与天花板，两座连廊有随雨雪展开的卷棚。降水消退并连续干燥一段时间后，顶棚逐渐收回。天气和画质切换不会重新排列城市、车辆、人物或植物。

## 右键落书仍然可用

在七层固定回廊的可通行空地轻点右键，会落下三本书。一位同层、正在闲暇的现有住客沿合法回廊路线走来，收齐后抱到柜边还书台；书在台面上渐隐归档，居民再回原来的活动位置。Mac 可用 Control + 左键，触屏在空地长按 650 毫秒；右键拖动继续转头。

这个互动只接受实际命中的、安全可达的固定回廊空地。花园、屋顶、家具、移动桥、升降平台、楼梯和空洞不接受落书。每层最多一件整理任务，全塔最多保留三组书，包含正在淡出的完成事件。没有可用住客时不会留下无人处理的书，也不会积累无限等待队列。花园访问与整理工作使用同一套现有居民，单个人不会同时承担两件任务。

## 保留的钟塔生活

七层环形回廊、三组贯穿各层的固定楼梯、两个独立升降轿厢和两条转桥继续运行。居民在 67 个家具活动点、297 个回廊观景点与 18 个花园活动点之间生活，沿楼梯、桥梁、轿厢和门廊完成通行；儿童、成年人和长者保有各自的比例、步态与关节动作。

建筑保留石材、彩窗、古铜细节、阅读壁龛、工作台、深蓝灰屋顶和罗马数字。外围依次连接园林、环形车道、停车场、石砖街屋和远处高楼。声音包含轻声环境、脚步、机构低鸣及整点钟声，只在用户主动开启后开始。

浏览器允许本地存储时，世界会保存人物、路径、预约、桥梁、天气设置、花园访问和整理任务，重新打开后连续恢复。1.5.1 的有效旧存档可以迁移，原来的人物、位置、任务和交通预约先连续恢复；新访客保持未入场，再逐步参加白天生活。页面在后台时不会把离开期间的数小时压缩为一次人物跳动。

## 验证与实际限制

当前专项为 `population`、`population-main`、`visitor-spaces`、`door-clearance` 和 `ground-access`。它们分别检查昼夜人口及任务/存档、真实主页面接线与实例显示、新增停留处及门亭的实体净空、门与台座书柜之间的几何关系，以及三处入口的通行。最终执行过的检查、结果文件、适用范围与源码哈希，以 [qa/release-verification.json](qa/release-verification.json) 为准。

1.5.1 的原始源码与检查报告保存在 `qa/baseline-v1_5_1/`，相应设计在 `design/experience-v1_5_1.md`；更早基线继续保留。历史结果不等于本轮重新执行的结果，`npm test` 也不表示重跑完整 12 小时人流模拟。

**当前制作环境无法进行 WebGL 实机画面验收。** 几何、路径、脚底高度、相机碰撞与状态联动使用实际 Three.js 对象检查；页面联动使用 DOM 和无绘制渲染器夹具。CPU 构图只用于检查模型布局，不能当作 GPU 截图。GPU 着色器、最终光照观感、真实触控设备与帧率尚未验收，因此不承诺具体 FPS 或加载秒数。

人物、书墙和植物采用程序建模。静水池、降水和卷棚没有完整的流体、积水、积雪或布料物理解算，居民也不会走入机动车道。浏览器若禁止本地 HTML 保存数据，当次运行仍然可用，关闭后无法保留进度。

## 开发和复核

```sh
npm install
npm run build
npm test
```

依赖固定为 Three.js 0.180.0 与 esbuild 0.25.10。构建生成自包含 HTML。`npm test` 默认运行本轮五个当前专项，也可以分别运行：

```sh
npm run test:population
npm run test:population-main
npm run test:visitor-spaces
npm run test:door-clearance
npm run test:ground-access
```

以前的独立测试脚本和 `package.json` 中对应命令仍保留，按需要单独调用；其中部分检查针对历史版本契约，应结合对应基线理解结果。CPU 构图辅助脚本不参与网页构建，额外需要 Python、Pillow 与 C++ 编译器，也不代替浏览器验收。

Three.js 的 MIT 许可保留在 `THIRD_PARTY_NOTICES.txt` 与独立 HTML 的结尾。源程序和模型为本项目制作，没有下载影视或游戏的场景资产。
